# Haptell 02 PAM8403/VG2230001H Shape-Only Blocking Firmware

This beginner-friendly firmware is for the Arduino UNO R4 WiFi + PAM8403 +
Vybronics VG2230001H 70 Hz actuator hardware path.

It supports only custom `shape` playback from the Haptell Shape Designer. The
shape controls the amplitude of a fixed 70 Hz sine carrier generated by the
Arduino UNO R4 WiFi DAC.

## Device ID

```text
haptell-02-pam8403-shape
```

Use this exact target in UDP commands. This firmware does not accept `all`, so
it can share a WiFi network with the DRV2605L haptell-02 shape firmware without
both devices starting accidentally.

## Command

```text
haptell-02-pam8403-shape shape duration=15000 points=0:80,500:180,12000:80,15000:0
```

Rules:

- maximum duration: `15000 ms`
- maximum points: `30`
- first point time must be `0`
- first point intensity may be any value from `0` to `255`
- last point time must equal `duration`
- last point intensity must be `0`
- point times must increase

## Safety Note

`MAX_DAC_SWING_COUNTS` is conservative. Increase it only after measuring
differential AC Vrms across the connected actuator.

## Compile

```powershell
arduino-cli compile --fqbn arduino:renesas_uno:unor4wifi firmware/haptell_02_uno_r4_wifi_pam8403_vg2230001h_shape_blocking
```
