# Haptell 05 Servo Shape Designer

This local Node.js web tool designs custom angle patterns for the `haptell-05`
weighted servo actuator.

## Start

From the repository root:

```powershell
node tools/haptell_05_servo_shape_designer/server.js
```

Then open:

```text
http://127.0.0.1:8084
```

No npm packages are required.

Optional:

```powershell
$env:HAPTELL_05_WEB_HOST = "127.0.0.1"
$env:HAPTELL_05_WEB_PORT = "8084"
node tools/haptell_05_servo_shape_designer/server.js
```

## Supported Firmware

Use this firmware:

```text
firmware/haptell_05_uno_r4_wifi_servo_weight_shape_blocking/
```

The firmware accepts the direct command generated by this tool:

```text
servo-shape duration=800 points=0:135:linear,120:175:easeOut,260:95:easeInOut,800:135:easeOut
```

## What the UI Does

- Draws one large angle-vs-time graph.
- Shows a `135 deg` neutral line.
- Shades the default safe range.
- Lets keyframes be dragged directly on the graph.
- Shows a point table with `time`, `angle`, `pulse us`, and `easing`.
- Shows the exact UDP command preview.
- Saves and loads JSON pattern files.
- Warns when a segment asks for more speed than the servo can likely deliver.
- Includes presets: `Nudge`, `Swing`, `Kick`, `Recoil`, and `Wobble`.
- Animates a small servo horn preview using the same easing curves.

## Pattern Limits

- maximum duration: `15000 ms`
- maximum points: `30`
- angle: `0..270 deg`
- neutral angle: `135 deg`
- pulse range: `500..2500 us`
- easing values: `linear`, `easeIn`, `easeOut`, `easeInOut`

The designer defaults to ending at neutral, but it allows non-neutral final
angles and warns about them.

## JSON Format

```json
{
  "schema": "haptell-servo-shape-pattern/v1",
  "durationMs": 800,
  "servo": {
    "minAngleDeg": 0,
    "maxAngleDeg": 270,
    "neutralAngleDeg": 135,
    "minPulseUs": 500,
    "maxPulseUs": 2500,
    "safeMinAngleDeg": 20,
    "safeMaxAngleDeg": 250
  },
  "points": [
    { "timeMs": 0, "angleDeg": 135, "easing": "linear" },
    { "timeMs": 120, "angleDeg": 175, "easing": "easeOut" },
    { "timeMs": 260, "angleDeg": 95, "easing": "easeInOut" },
    { "timeMs": 800, "angleDeg": 135, "easing": "easeOut" }
  ]
}
```

Device IP address and UDP port are not saved in the JSON file.

## Speed Warnings

The tool compares each segment against a conservative no-load servo speed:

- warning above about `280 deg/s`
- red warning above about `333 deg/s`

This is based on the user's `0.18 sec / 60 deg` speed at `4.8 V`. Real motion
with an offset weight can be slower, especially near hard direction changes or
when the weight has high inertia.

## Troubleshooting

If the web UI reports that UDP was sent but the device does not react:

- confirm the Arduino Serial Monitor shows the expected IP address
- confirm the web UI uses that IP address
- confirm the firmware is listening on UDP port `4444`
- confirm the command starts with `servo-shape`
- check that the board is not still busy playing a previous blocking shape
- confirm servo supply ground is connected to Arduino ground
